The Problem

Most group music is either dominated, chaotic, or boring.

One person controls the speaker, everyone dumps songs into the queue, or the group settles for a playlist that does not really match who is there. Jammix is built to solve the next-song decision.

How It Works

  1. Host creates a room.
  2. Guests join with Spotify.
  3. Jammix reads shared taste signals.
  4. The queue updates as the room changes.
  5. The host can guide the vibe and the room can vote.

Core Features

Designed around the room, not just the queue.

Adaptive queue

Builds a live mix from top tracks, artists, recent plays, and saved songs.

Fair group control

Majority skip voting and protected manual adds keep the session social.

Prompt steering

The host can nudge the room toward a vibe without turning recommendations rigid.

Spotify export

The final session can be saved as a Spotify playlist in room order.
